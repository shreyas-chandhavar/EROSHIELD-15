# Public reference data

The V2 Octave script automatically downloads the station-specific public IEA 15-MW AeroDyn polar files it needs from the pinned public release used during the project.

Primary source:
- https://github.com/IEAWindSystems/IEA-15-240-RWT

The project used the public IEA 15-MW outer-blade geometry, airfoil assignments and AeroDyn polars as reference inputs. These third-party files are not presented as original project work.
