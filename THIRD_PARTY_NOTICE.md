# Third-party data and attribution

EROSHIELD-15 is an independent engineering study based on the public
IEA 15-240-RWT reference turbine.

Primary public model source:
- IEAWindSystems / IEA-15-240-RWT
- https://github.com/IEAWindSystems/IEA-15-240-RWT
- Repository license recorded during the project: Apache License 2.0

Public IEA files included or referenced here are retained as third-party source material and
are not presented as original project work.

Project-specific work includes the CAD reconstruction, protection concept, Octave/MATLAB
screening code, differential BEM analysis, mass/load calculations, design decisions, and
engineering change-control documentation.

No repository-wide license is being imposed on the project-specific work by this closeout
package. Add a license later only if you explicitly want to grant reuse rights.
