The project used native SolidWorks CAD locally. The native `.SLDPRT` / `.SLDASM` files were not transferred into this repository during closeout.

Controlled CAD names used during the project included:
- `PRT-1310_IEA15MW_OUTER_BLADE_SEGMENT`
- `PRT-1320_EROSHIELD_LE_SHIELD`
- `ASM-1300_EROSHIELD_OUTER_BLADE`

The project stopped before the proposed Phase-12 feathered-termination redesign was completed.
